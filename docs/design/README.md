# Design notes (historical)

These are per-country design notes written **before** the work landed and kept
as the record of what was decided and where the implementation deviated from the
plan. Every one is marked `IMPLEMENTED`; their "Implementation outcome" sections
are the durable part.

**They are not the current specification.** `AGENTS.md` is. Where a note and
`AGENTS.md` disagree, `AGENTS.md` wins; where a note and `docs/SOURCES.md`
disagree about a legal reference, `SOURCES.md` wins. Notes exist for only two of
the supported countries — this is an archive, not a pattern to complete.

The verification recipes these notes contained (the BOE block IDs, the KBA table
refresh) now live in `docs/SOURCES.md`, next to the sources they apply to, since
that is where a maintainer preparing a metadata release looks.
