libplate

Implementation examples — format validation, parsing and structured analysis of European vehicle registration plates. See the README for the full list of supported schemes.

libplate validates known plate formats and extracts the information encoded in them. It cannot prove that a plate has been issued, is currently assigned, or belongs to the observed vehicle.

1. parse — the primary API

Use parse whenever you need the reason, the matched scheme, or the vehicle inferences. Everything else is a thin convenience over it. 

import { parse } from "libplate";

const result = parse("R-1234-BCD", { country: "ES" });

result.status;                 // "VALID"
result.normalized;             // "R1234BCD"   (canonical, no separators)
result.formatted;              // "R 1234 BCD" (national display format)
result.scheme.id;              // "ES_TRAILER_CURRENT"
result.scheme.name;            // "Remolques y semirremolques"
result.scheme.components;      // { prefix: "R", serial: "1234", series: "BCD" }
result.scheme.sourceRefs;      // ["ES-RGV (Anexo XVIII, I.A.c)"] — legal basis

result.registration.type;      // "ORDINARY"
result.vehicle.category;       // "TRAILER_OR_SEMITRAILER"
result.vehicle.inferenceLevel; // "DETERMINISTIC" — the R prefix decides it
result.vehicle.evidence;       // [{ type: "PREFIX", value: "R" }]
result.visual;                 // { background: "RED", foreground: "BLACK" }

Category inference is honest about its limits: an ordinary Spanish plate like 1234 BCD reports inferenceLevel: "NOT_INFERABLE" because the text alone cannot distinguish a car from a van.

2. validate / format — conveniences

import { validate, format } from "libplate";

validate("1234 BCD", { country: "ES" });  // true
validate("1234 BCÑ", { country: "ES" });  // false (Ñ is not in the series charset)

format("1234-bcd", { country: "ES" });    // "1234 BCD"
format("aa123aa",  { country: "FR" });    // "AA-123-AA"
format("garbage",  { country: "ES" });    // null when invalid

3. detect — no country hint

detect tries every supported country. When exactly one scheme matches you get a normal result; when several match, the status is "AMBIGUOUS" and candidates lists them — the library never guesses a single country. 

import { detect } from "libplate";

detect("C 1234 BCD");
// status:  "VALID"
// country: "ES", scheme.id: "ES_MOPED_CURRENT"
// vehicle: { category: "MOPED_OR_MOTOR_CYCLE", inferenceLevel: "DETERMINISTIC" }

detect("BAB123");
// status: "AMBIGUOUS", errors[0].reason: "AMBIGUOUS_SEGMENTATION"
// candidates: [
//   { country: "DE", scheme: "DE_STANDARD", formatted: "B-AB 123" },  // Berlin
//   { country: "DE", scheme: "DE_STANDARD", formatted: "BA-B 123" },  // Bamberg
// ]

detect("B-AB 123");
// status: "VALID" — the separators you wrote are used as evidence

4. Options: referenceDate and includeHistorical

import { parse, detect } from "libplate";

// Legacy Spanish provincial series (1971-2000): valid with a country hint.
parse("M-1234-AB", { country: "ES" });
// status: "VALID", scheme.id: "ES_PROVINCIAL_1971_2000"

// referenceDate filters schemes by their validity period.
parse("M-1234-AB", { country: "ES", referenceDate: "1985-06-01" });
// status: "VALID" — the series was being issued in 1985

// Historical schemes are opt-in for country-less detection, because their
// shapes collide across countries and would flood results with ambiguity.
detect("00-00-AA");                             // status: "INVALID"
detect("00-00-AA", { includeHistorical: true });
// status: "VALID", country: "PT", scheme.id: "PT_GENERAL_1992_2005"

5. Driving UI logic from reason codes

errors[*].reason carries stable machine-readable codes, so you never have to parse human messages. 

import { parse } from "libplate";

function plateFieldFeedback(input, country) {
  const result = parse(input, { country });

  switch (result.status) {
    case "VALID":
      return { ok: true, display: result.formatted };
    case "AMBIGUOUS":
      // Let the user pick among result.candidates
      return { ok: false, choices: result.candidates };
    default:
      switch (result.errors[0]?.reason) {
        case "TOO_SHORT":
        case "TOO_LONG":
        case "INVALID_LENGTH":
          return { ok: false, hint: "Check the plate length" };
        case "INVALID_CHARACTERS":
          return { ok: false, hint: "Contains characters no scheme allows" };
        case "UNSUPPORTED_COUNTRY":
          return { ok: false, hint: "Country not supported yet" };
        default:
          return { ok: false, hint: "Not a recognized plate format" };
      }
  }
}

6. Introspection

import {
  getSupportedCountries,
  getSupportedSchemes,
  getMetadataVersion,
  getLibraryVersion,
} from "libplate";

getSupportedCountries();     // ["BE", "DE", "ES", "FR", "IT", "NL", "PT"]
getSupportedSchemes("ES");   // ["ES_ORDINARY_CURRENT", "ES_TRAILER_CURRENT", ...]
getMetadataVersion();        // e.g. "2026.07.3" — the compiled scheme tables
getLibraryVersion();         // e.g. "0.1.0"
